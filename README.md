# 日程系统

本地优先的日程管理应用，支持周 / 月 / 年三种视图，重复日程、拖拽调整、完成标记、版本历史撤销与一键导出图片。

## 功能

- **三种视图**：周视图时间轴（可缩放、凌晨折叠）、月视图日历 + 当日看板、年视图总览
- **重复日程**：每天 / 每 N 天 / 每周 / 每月 / 工作日 / 周末，可设截止日期，实例级完成标记
- **拖拽交互**：时间块拖拽改期、全天事件横向跨天拉伸、边界拖拽改重复范围
- **完成追踪**：单次与重复日程实例级完成标记，过期未完成自动变暗红
- **撤销历史**：操作可撤销 / 重做，历史持久化在 `历史版本/versions.json`，刷新后仍在
- **导出**：一键导出当前视图为 JPG（剪贴板优先，失败回退下载文件）

## 快速开始

```bash
npm install
npm run dev   # http://localhost:4321
```

Windows 下可直接双击 `启动器.bat`，使用图形化启动器管理服务的启停与日志。
